# CarpoolNetwork

Community-driven ridesharing for a more sustainable commute.

**Live at [carpoolnetwork.org](https://carpoolnetwork.org)**

## About

CarpoolNetwork connects commuters for shared rides, reducing traffic, emissions, and transportation costs in local communities.

## Stack

- **Framework**: Next.js (App Router)
- **Database**: Supabase
- **Hosting**: Vercel
- **Styling**: Tailwind CSS
